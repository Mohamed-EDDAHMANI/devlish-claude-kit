# Tests

1. Find the test tool and the style already used in the project.
2. List the behaviour to cover: the normal case, edge cases, failure cases.
3. For a bug, write a test that fails first, then fix the code.
4. Test what the code does, not how it does it.
5. Run the tests and show the real result.

Never delete or weaken a test to make it pass.
